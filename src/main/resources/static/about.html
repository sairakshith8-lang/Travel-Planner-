About TravelMate

Empowering Modern Travelers

Designed as an academic full-stack software engineering project, TravelMate solves the chaos of travel planning with clean architecture, smart day-by-day itineraries, and dynamic financial tracking.

🎯 Our Purpose & Vision

Travel planning is often fragmented across multiple tabs, messy spreadsheets, and forgotten notes. TravelMate was developed to unify every aspect of journey planning into one elegant, user-friendly system.

Whether embarking on a coastal getaway to Goa, a scenic trek in Manali, or a heritage tour across Rajasthan, travelers can establish clear daily itineraries, allocate budget categories, and compare actual expenses against initial estimates in real time.

💻 Technical Architecture

  • ☕ Backend: Java 17+, Spring Boot 3, Spring Data JPA, Spring Security Crypto (BCrypt), REST APIs.
  • 🐬 Database: MySQL relational schema with Foreign Keys, indexed queries, and H2 test profile.
  • 🎨 Frontend: Semantic HTML5, Vanilla CSS3 (Custom Design System), JavaScript (Fetch API & DOM manipulation).
  • 🔒 Security: Session-based authentication, user-scoped data isolation (users cannot access other users' private trips).
